# Security

Report vulnerabilities through [GitHub’s private reporting form](https://github.com/sal0-h/feurtube/security/advisories/new). Include the affected commit or dependency and steps to reproduce. Keep credentials, account data and signing keys out of reports.

This covers FeurTube’s current source and pinned build dependencies. Use the [issue forms](https://github.com/sal0-h/feurtube/issues/new/choose) for setup, Shorts or playback bugs.
