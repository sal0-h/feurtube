# Implementation

`feurtube` verifies two release downloads, compiles our extension with `javac` and SDK D8, then compiles a JVM patch against the pinned CLI and RVX bundle. It combines the policy with RVX because Morphe isolates the class loader of each input bundle; a patch that calls `dependsOn()` on RVX must share its loader. The generated bundle contains RVX's unchanged JVM classes and extension plus our classes and extension DEX. Its original manifest and the lock file are retained inside the archive. The Android patch-manager DEX is omitted, so this is a desktop-only bundle.

The patch command uses `--exclusive`. It selects GmsCore support, the settings entry, branding, Shorts launcher shortcut removal, stream-support hooks, and FeurTube policy. The policy declares dependencies on RVX's Shorts components, navigation components and startup-resume patch. Their own dependencies supply the rendering and navigation hooks. We do not select ad removal, background-play unlocks, alternative downloaders or app-version spoofing.

RVX fingerprints find YouTube's obfuscated methods by their instructions, strings and structure. Its Litho filter matches component identifiers such as `shorts_shelf`, `inline_shorts` and `shorts_video_cell`. Navigation hooks hide the Shorts button. Its startup patch intercepts the resume decision. YouTube version support comes from those upstream fingerprints, not from the FeurTube settings hook.

`FeurTubePatch` hooks the terminal constructor of the injected upstream `Setting` class. Before it stores the default and loads saved preferences, it calls `ShortsPolicy.defaultValue(key, original)`. We enable Shorts hiding and disable stream spoofing by default. This preserves upstream preference persistence and reset behavior. Existing saved preferences can override these defaults.

The policy also replaces the upstream `openShortInRegularPlayer(String)` method with a delegate to `ShortsPolicy.openShort`. That method opens an individual video through RVX's `vnd.youtube://` route and consumes the original Shorts navigation. Unlike upstream's implementation, it also consumes empty-ID launches and redirects while the selected tab is Shorts. Errors are logged and consumed. This covers routes that reach the upstream hook; it is not evidence that every YouTube entry point reaches it. A small resource overlay replaces the upstream player-type selector with a fixed explanation, since that selector cannot change FeurTube's policy.

The host tests run the runtime policy with compile-only test doubles, modify the **actual released RVX extension DEX**, round-trip that mutation through a DEX writer, and load the combined bundle through Morphe. The test doubles are excluded from the injected DEX. APK installation and playback require separate Android tests.

GmsCore changes package/signature integration and includes stream-spoof hooks as a dependency. Omitting the visible stream patch would not remove those hooks. We override the stream-spoof default to false; ordinary playback may fail on a modified app. Enabling a workaround can change available formats or other account features. Premium compatibility is a release criterion, not an assumption.
