A few questions

What is FeurTube?

An open-source patch project for Android YouTube. It uses Morphe and RVX patches, with a small FeurTube policy that hides Shorts by default and routes shared Shorts to the regular player.

Is there an APK I can download?

There is no public prepatched APK. Use the local build guide with a supported YouTube APK.

Will my Premium subscription still work?

Background playback and native offline downloads worked with Premium on the first test device. That does not establish compatibility with every Premium feature. PiP, casting, enhanced bitrate and other features still need broader testing.

What is GmsCore, and why is it needed?

ReVanced GmsCore is a microG fork that supplies Google-service compatibility to the modified app without root. It runs beside your existing Google Play Services and participates in sign-in and token handling. Read the trust notes before signing in.

Can I keep the official YouTube app?

Yes. FeurTube uses a separate package, app.feurtube.android. It can be installed alongside stock YouTube. Set supported-link preferences to choose which app opens shared YouTube links.

Is this an official YouTube project?

No. FeurTube is independent of Google and YouTube.

Where do I report a problem?

Use the bug-report forms for build or app problems. Include the YouTube and Android versions and steps to reproduce. Report security vulnerabilities through GitHub’s private reporting form. Keep account details, tokens and raw phone logs out of public reports.

FeurTube is an unofficial Android patch project. Not affiliated with Google or YouTube.
